# User manual

## Access

Use the desktop client to sign in with a valid username and password. The API enforces role-based access and session expiry.

## Common tasks

### Billing

- Generate monthly billing for the selected period.
- Review invoices and account balances.
- Keep track of outstanding and overdue amounts.

### Payments

- Post cash or GCash payments.
- Verify GCash proof submissions.
- Approve or reverse payments when needed.

### Collections

- View collection areas, collectors, and batch activity.
- Monitor collector accountability and end-of-cycle reconciliation.

### Reporting

- Review dashboard totals, aging summaries, and payment activity.
- Export monthly or period-based reports using the reporting layer.

## Roles

The system is designed around admin, cashier, auditor, and viewer roles as well as collection-oriented and operational responsibilities.
